## Problems & Troubleshooting

### SSH connection and host key mismatch

- The initial SSH connection on port 22 was refused.
- SSH access was configured on port 2222.
- The next connection attempt reported a host key mismatch.
- Verified the new ED25519 host key fingerprint directly on the Ubuntu VM.
- Confirmed that the fingerprint matched the new key reported by the SSH client.
- Removed the stale host key entry from the host machine's `known_hosts` file.
- Successfully connected to the VM.

## What I Learned

- Why a host key mismatch should be investigated rather than blindly ignored.
