# 2026-11-04 — Docker: First Nginx Container

## Completed

- Installed Docker Engine using the official Docker APT repository.
- Verified that Docker Engine works correctly.
- Downloaded the official Nginx image.
- Created and started an Nginx container.
- Published container port `80` to host port `8080`.
- Accessed the Nginx welcome page from MacBook through Tailscale.
- Inspected container configuration and runtime state.
- Reviewed Nginx startup logs and HTTP access logs.
- Stopped, restarted, and removed the container.
- Verified that the Nginx image remained available after container removal.

## Technical Details

- Container name: `nifty_goldwasser`
- Image: `nginx:latest`
- Nginx version: `1.31.8`
- Container port: `80`
- Host port: `8080`
- Network mode: `bridge`
- Container IP: `172.17.0.2`
- Container status during inspection: `running`

## What I Learned

- Difference between Docker images and containers.
- How to publish container ports.
- How Docker bridge networking works.
- How to access a containerized service from another machine.
- How to inspect container configuration and runtime state.
- How to read container logs and identify HTTP status codes.
- Difference between stopping and removing a container.
- Removing a container does not automatically remove its image.

## Problems Encountered

- Initially ran `docker logs` and `docker inspect` without specifying a container name. Learned that both commands require a container identifier.
- Nginx returned `404` for `/favicon.ico` because the default image did not contain that file. The main page returned `200` successfully.
