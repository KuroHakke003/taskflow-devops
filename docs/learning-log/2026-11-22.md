# Learning Log — November 22, 2026

## Kubernetes — Networking, Ingress & TLS

### 1. Ingress Controller
- Enabled and deployed Traefik Ingress Controller in the K3s cluster.
- Learned the role of an Ingress Controller in Kubernetes and how it handles external HTTP/HTTPS traffic.
- Verified Traefik deployment and its LoadBalancer service through K3s ServiceLB.

### 2. Kubernetes Ingress
- Created a Kubernetes Ingress resource for TaskFlow.
- Configured hostname-based routing using `taskflow.local`.
- Routed incoming HTTP traffic to the `taskflow-api` Service on port `8000`.
- Tested routing to `/`, `/tasks` and `/docs`.

### 3. Networking & NetworkPolicy Troubleshooting
- Investigated a `502 Bad Gateway` error caused by the API NetworkPolicy blocking traffic from Traefik.
- Identified that Traefik runs in the `kube-system` namespace.
- Updated the API NetworkPolicy to allow ingress traffic from Traefik using namespace and pod selectors.
- Verified that external traffic could successfully reach the API through Ingress.

### 4. Local DNS Configuration
- Configured `/etc/hosts` on the Linux VM and macOS to resolve `taskflow.local` to `192.168.1.19`.
- Verified hostname resolution and external access from the Mac.
- Tested access through the browser and command-line tools.

### 5. TLS / HTTPS
- Generated a self-signed TLS certificate and private key using OpenSSL.
- Added a Subject Alternative Name (SAN) for `taskflow.local`.
- Created a Kubernetes TLS Secret named `taskflow-tls`.
- Configured the Ingress to use the TLS Secret.
- Verified HTTPS access to TaskFlow `/docs` endpoint.
- Inspected the TLS certificate using OpenSSL.
- Tested HTTPS access from the Mac browser.
- Understood why self-signed certificates generate trust warnings and why `curl -k` was used for testing.

### 6. Troubleshooting & Practical Experience
- Diagnosed and resolved a 502 error between Traefik and the API.
- Investigated Kubernetes networking restrictions caused by NetworkPolicies.
- Verified HTTP and HTTPS access from both the VM and the Mac.
- Practiced external access troubleshooting across Kubernetes networking, services, Ingress and TLS.

- Understand how NetworkPolicies affect traffic between namespaces.

  - Enabled a read-only root filesystem.

- Learned the difference between Pod-level and container-level security contexts.
- Parameterized security settings through `values.yaml`.
