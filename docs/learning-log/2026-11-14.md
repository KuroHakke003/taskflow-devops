## 3. Alertmanager and Telegram Notifications

Configured Alertmanager to deliver monitoring alerts directly to Telegram.

- Created and configured a Telegram bot integration.
- Configured Telegram as an Alertmanager notification receiver.
- Stored the bot token in a separate secrets file instead of putting it directly into the configuration.
- Mounted the secret into the Alertmanager container.
- Configured file permissions and ownership so Alertmanager could read the token securely.
- Used the personal Telegram chat ID as the notification destination.
- Configured alert grouping and notification timing:
  - `group_wait: 10s`
  - `group_interval: 30s`
  - `repeat_interval: 4h`
- Enabled resolved notifications using `send_resolved: true`.
- Troubleshot Telegram notification failures, including permission issues and HTTP 403 responses.

Successfully received Telegram notifications from Alertmanager.
